# 能力边界

当前适合本地学习、工程演示和二次开发。功能接口与测试的存在不构成生产验收。

| 范围 | 当前说明 |
| --- | --- |
| 预约与订单 | 有库存重校验、请求重放和状态记录；并发证据来自独立合成环境 |
| 支付 | 默认 DEV Provider；支付宝沙箱需要使用者自行配置和确认，公开模板保持关闭 |
| 储值 | DEV 分账、退款、审批与对账；代码关闭生产资金入口 |
| 邮件 | 模板关闭 SMTP 外发；Mailpit 仅用于本地接收，生产找回密码邮件闭环有遗留项 |
| 广告 | 受控开关和合成归因实验；未证明真实商业效果、生产投放或自动计费 |
| 部署 | 有本地启动与容器配置；生产迁移、备份恢复、多实例长稳、SLA 尚未验证 |
| 浏览器 | 本次实际覆盖范围见发布验证记录；不能由桌面浏览器测试推导真机支持 |
| 数据 | 初始化数据与演示账号为合成示例；不提供真实用户数据或可复用生产数据库 |
| 时间 | 储值流程使用本地日期时间；JVM、数据库和 JDBC 时区需保持一致。独立储值验证统一为 `Asia/Shanghai`，跨时区部署尚未验证 |
| 性能 | 历史数据注明硬件、负载和代码版本；不表达生产最大容量 |

历史实验页面读取精选静态报告。依赖升级或源码变化后，原报告只说明原被测版本，不自动说明当前构建。新运行会保存到忽略目录 `engineering/runs/`。
