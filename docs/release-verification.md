## 失败与修复记录

依赖升级后的 SQL 次数测试曾把 Connector/J 发出的大小写不同的会话控制语句计入业务查询。仅修正测试对 SQL 文本的大小写转换，业务查询上限保持不变；针对性回归和最终完整回归通过。

先前完整运行的容量列表 p95 为 1,012 ms，门槛 800 ms，未通过；并行验证时广告归因 p95 为 1,838 ms，门槛 1,000 ms，未通过。记录这些失败后停止本任务的构建、演示及实验服务，再在同一机器独立完成上述全部后端测试，原有性能门槛通过。没有放宽门槛或从测试中删除失败场景；复测通过不证明生产 SLA，也不能单凭这一变化确定失败的唯一原因。

Docker Hub 在本环境超时；实际构建使用 `m.daocloud.io/docker.io/library/` 的基础镜像，以及 `https://maven.aliyun.com/repository/public` 的 Maven 镜像。公开模板默认仍为上游来源，替换入口只接受维护者自行选择的构建配置。本地首轮预下载缓慢，改为正常打包与 BuildKit 依赖缓存；Nginx 文件挂载失败后使用镜像内配置。测试期间一次重启中断了旧合成库迁移；该库保留，最终改用新的独占卷完成全量迁移，没有自动修复或改写 V1–V36。

真实浏览器检查发现 `/engineering` 与静态材料目录重名，引发错误重定向，已修正 Nginx 的 SPA 回退并通过三内核检查。实验工具首次启动在下载新插件期间超过 150 秒，等待窗口改为 600 秒；后续实际实验全部通过。
